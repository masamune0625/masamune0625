GitHubを「発注者に伝わる営業ページ」に変えるサービス **[Folio](https://folio.akima-inc.co.jp)** を作っています。
Next.js / TypeScript / Supabase / Claude API で開発しています。

## 🧰 Folio — GitHubが、あなたの営業ページになる

GitHubのユーザー名を入れるだけで、技術の言葉を発注者が読んで分かる言葉に翻訳した営業ページを自動で作る無料サービスです。

- **営業ページの自動生成**: 得意なこと・制作事例・16タイプを、発注者に伝わる言葉でまとめる
- **プロダクトの保管庫**: 作ったものを画像・動画つきで公開、いいねが集まるとFolioが特集
- **案件レーダー(β)**: 受け取りをオンにした人にだけ、スキルの合う案件相談が届く
